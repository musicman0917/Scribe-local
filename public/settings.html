Settings

Local Ollama Connection

Scribe Local uses a locally running Ollama instance with a vision-capable model (e.g. llava or llama3.2-vision) for smart cropping and auto-generated step descriptions. No data leaves your machine.

Must be a vision-capable model already pulled in Ollama (ollama pull llava).

Click Annotation Style

Customize the semi-transparent highlight and number badge overlaid on every captured click.

Automatic Step Titles

When available, Scribe Local asks the OS which UI element you clicked and titles the step Click "Save" automatically, instead of a generic Step 3. Currently only supported on Windows (via .NET UI Automation, no extra install needed). On other platforms, or when disabled, steps get generic titles — you can still rename them by hand or use Auto-Describe.

⚠ Security & Compliance Notice

This tool captures raw screenshots of your desktop and sends cropped images to your local Ollama instance. It is not designed, audited, or certified for capturing financial data, Protected Health Information (PHI), or any HIPAA-regulated data. Always review captured screenshots before exporting or sharing, and use the redaction tool to blur or black out any sensitive information such as stream keys, passwords, tokens, or personal data.
